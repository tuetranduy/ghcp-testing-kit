# Step 1: Context & Role-play

---

## Purpose

Establish the **Senior QA Engineer** role and load the project context so the AI adopts a testing-expert mindset. This step narrows the AI's knowledge space, making its answers more in-depth and grounded in reality.

## How to use

1. Open the `prompt.txt` file in this folder.
2. Copy the content below the `---START---` line.
3. Replace the parts in `[...]` with real data:
   - **Project / feature name** to be tested
   - **System context** (a short description of the current app)
   - **MVP goal** (the testing scope for this round)
   - **Attached documents** (Requirements, User Stories, Figma, PDF, etc.)
4. Paste it into the AI chat and send.
5. Wait for the AI to confirm **"I understand the context and am ready"** before moving to Step 2.

## Notes

- The more detailed the documents, the more accurate the AI's analysis.
- If you have Figma or screenshots, add descriptions of the important UI elements.
- This step only needs to be run **once** at the start of the conversation.
