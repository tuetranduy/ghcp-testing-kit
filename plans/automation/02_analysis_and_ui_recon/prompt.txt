## Task

Use the **browser tools** (Playwright MCP / Selenium MCP) to:

1. **Open the browser** with the provided URL (viewport 1920x1080)
2. **Navigate** through each step in the Test Cases
3. **Collect** all the required locators by:
   - Reading the Accessibility Tree
   - Inspecting DOM attributes: `id`, `data-testid`, `name`, `aria-label`, `role`, `placeholder`
   - NEVER **guessing** selectors — only take them from the real DOM
4. **Prioritize** locators in this order (see `.agents/rules/locator_strategy.md`):
   - Playwright: `getByRole` > `getByLabel` > `getByPlaceholder` > `getByTestId` > CSS > XPath
   - Selenium: `id` > `data-testid` > `name` > `cssSelector` > `xpath`
5. **Return the results** as a table:

| Page | Element | Locator Type | Locator Value | Fallback Locator |
